# GardenChain

A decentralized urban gardening reward system that gamifies plant cultivation and sustainable growing practices on Stacks blockchain.

## Features

- Crop planting and harvesting with yield quality tracking
- Progressive cultivation leveling system
- Composting mechanics with seasonal bonuses
- Companion planting for advanced gardeners
- Seed bank creation and preservation rewards
- Comprehensive gardening statistics and analytics

## Smart Contract Functions

### Public Functions
- `plant-seeds` - Plant crops with variety and plot size specification
- `harvest-crops` - Harvest crops and earn rewards based on yield quality
- `claim-garden-rewards` - Claim accumulated garden tokens
- `start-composting` - Begin composting process for enhanced rewards
- `harvest-compost` - Complete composting with seasonal bonuses
- `plant-companion-crops` - Plant companion crops for bonus rewards
- `create-seed-bank` - Create seed banks for preservation bonuses

### Read-Only Functions
- `get-gardening-activity-count` - Get total gardening activities for user
- `get-garden-token-balance` - Get current token balance
- `get-cultivation-level` - Get current cultivation mastery level
- `get-harvest-count` - Get total number of harvests completed
- `get-composting-materials` - Get current composting materials amount
- `get-seasonal-bonus` - Get current seasonal yield bonus
- `get-garden-stats` - Get platform-wide gardening statistics
- `calculate-harvest-reward` - Calculate potential harvest rewards

## Gardening Mechanics
- Crop variety affects growing time requirements
- Yield quality scores (0-100) provide bonus rewards
- Composting adds seasonal bonuses to future harvests
- Companion planting unlocks at higher cultivation levels
- Early composting harvest incurs penalties

## Usage

Deploy the contract to create a gamified urban gardening ecosystem where gardeners can earn rewards for sustainable cultivation, composting, and seed preservation.
